The **📝 Summary** tab holds a plain-text project report in a dark,
console-style panel, filled in once a run finishes, together with the
toolbar of export buttons used to save it in other forms.

<Screenshot id="bess-results-summary" />

## What the report contains

The report runs in a fixed order:

1. A project header and configuration block.
2. A CAPEX, IRR and NPV headline.
3. A **FINANCIAL METRICS** block, including an **[ABOVE 15%]** or
   **[BELOW 15%]** tag on the headline IRR line — compared against the same
   fixed 15% benchmark as the IRR badge on
   [the dashboard](/bess/results/dashboard), not the **Project Target IRR**
   field.
4. A **MONTHLY DFR COMPLIANCE (Year 1)** table.
5. A **YEAR-BY-YEAR CASHFLOW** table.

## Export toolbar

Six buttons run along the top of the tab, in this order:

1. **📥 Export PDF**
2. **💾 Save Plot**
3. **📄 Save Report**
4. **📊 Save DFR CSV**
5. **🕒 Time-Series CSV**
6. **📈 Sensitivity**

The first five are licence-gated exports — the same requirement as
**▶  Simulate**, **⚙  Optimise** and every other export in the application
(see [How access works](/bess/access/overview)). **📈 Sensitivity** is not
gated.
