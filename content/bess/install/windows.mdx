---
title: Install on Windows
description: Install BESS Desktop from the Microsoft Store, then launch it for the first time.
---

BESS Desktop is a Windows application, installed from the Microsoft Store. There
is one package and one installation route: search the Store for the
application, install it, launch it.

Installation does not need this device activated. The application opens
straight into its main window — every input tab is there to read and change.
Activation is only asked for when you run **▶ Simulate**, **⚙ Optimise**, or
export something.

## Publisher and platform

The listing is published by **Rensaar**. Check the publisher name on the
listing page before you install — it is what tells you you are looking at the
right application rather than a similarly named one.

BESS Desktop ships for Windows.

## Find the listing

<Steps>

<Step>
### Open the Microsoft Store

Press Start, type *Microsoft Store*, and open it.
</Step>

<Step>
### Search for BESS Desktop

Type the application name into the Store's search box.
</Step>

<Step>
### Check the publisher reads Rensaar

The publisher name sits under the application name on the listing page,
alongside the install button.

<Screenshot id="bess-install-store-listing" />
</Step>

<Step>
### Install it

Click **Get** or **Install**. The Store downloads and installs the
application; there are no options to choose along the way.

When it finishes, the button on the listing changes to **Open**.
</Step>

<Step>
### Launch it

Use **Open** on the listing, or find the application in the Start menu — press
Start and type the first few letters of its name.
</Step>

</Steps>

## The first launch

BESS Desktop does not show a start-up window and does not check whether this
device is activated before opening. The main window appears directly: the
left input notebook opens on its **📂 Data** tab, and the right result
notebook is empty until you run something.

The window opens at 1600×900 and starts maximised.

<Callout type="warn">
**▶ Simulate**, **⚙ Optimise**, and every export need this device activated.
Everything else — reading and changing every input, saving or opening a
project, loading a generation profile, and the **🏗 Plant Layout & SLD**
designer — works before that.
</Callout>

Help ▸ **License…** opens the window that shows this device's activation
status and Device ID. See [Getting started](/bess/getting-started) for what
activation involves and a full tour of the main window.
