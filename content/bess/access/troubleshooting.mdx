title: Access problems
description: Every access state the License window shows, what each one means, and the fix — plus the 3-day offline grace.
---

Help ▸ **License…** shows this device's access status at any time. The
headline is always one of three: **✓  Active**, **✗  No access**, or
**⏳  Waiting for activation** — the message beneath it says which state
applies and why.

<Accordions>

<Accordion title="Access active">

**What it means.** This device has active access. The headline reads
**✓  Active**, and the buttons beneath it are **Access Details**, **Refresh**
and **Close**.

**Nothing to fix.** **▶  Simulate**, **⚙  Optimise** and every export all
work.

</Accordion>

<Accordion title="Your access has ended. Contact SolarLayout to purchase a licence.">

**What it means.** This device's access has expired. The headline reads
**✗  No access**.

**Fix.** Contact SolarLayout at
[sales@solarlayout.app](mailto:sales@solarlayout.app) to arrange paid
access for this device, then click **Refresh** once it is issued.

</Accordion>

<Accordion title="Access has been revoked. Contact SolarLayout.">

**What it means.** Access for this device has been withdrawn. The headline
reads **✗  No access**.

**Fix.** Contact SolarLayout to resolve it, then click **Refresh**.

</Accordion>

<Accordion title="No active access for this device. Click 'Get Free Access' to get started.">

**What it means.** This device has never had access requested for it, or a
previous request was never completed. The headline reads **✗  No access**.

**Fix.** Click **Get Free Access** and complete activation in the browser
page it opens, then **Refresh**. See
[Activate this device](/bess/access/activate).

</Accordion>

<Accordion title="Waiting for activation">

**What it means.** This is shown right after clicking **Get Free Access**,
while activation is being completed in the browser.

**Fix.** Finish signing in and activating on the page that opened, then
return to the License window and click **Refresh**.

</Accordion>

<Accordion title="This device has been offline for a while">

**What it means.** When the device can't reach the server, it keeps working
under its last known status for up to 3 days.

**Fix.** Reconnect within those 3 days so the device can check in again.

</Accordion>

</Accordions>
