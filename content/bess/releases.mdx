This documentation doesn't carry a version history for BESS Desktop. What's
installed on your machine, and what's changed between versions, is recorded
by the Microsoft Store rather than by these pages — read it from there.

## Where your version lives

The application's own bottom status bar always shows the installed version
(for example **v1.1.0**) — that's the quickest place to check, and worth
including whenever you report a problem. If you need to confirm what the
Store itself has installed or is about to install, open the Store, go to
your **Library**, and find the application's entry. See
[Updates and reinstalling](/docs/bess/install/updates) for the exact steps.

## How an update reaches you

Updates arrive through the Store. Windows checks for them on its own
schedule and installs them in the background, so there's nothing to download
and nothing to run by hand. An update may wait until the application is
closed, so close it if one appears to be stuck. You can also check for one
by hand at any time — see
[Check for an update by hand](/docs/bess/install/updates#check-for-an-update-by-hand).
A copy that did not come from the Store receives no Store updates; the
download page,
[solarlayout.app/downloads/bess](https://solarlayout.app/downloads/bess),
always carries the current version.

Access to run an analysis isn't stored as a file the application keeps — it's
checked against SolarLayout's server by this device's Device ID, so an
update or a full reinstall doesn't disturb it. See
[Access is tied to this device, not a file](/docs/bess/install/updates#access-is-tied-to-this-device-not-a-file).
