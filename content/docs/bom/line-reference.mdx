This page lists every entry in **SolarLayout standard**, the built-in
[BOM profile](/docs/bom/profiles), in the order of the
[BOM view](/docs/bom/overview). An entry gives a line when it applies to your design
and the layout has something to count. A company or client profile starts from this
list and changes or adds to it.

## Reading the tables

**How it is counted:**

| Wording | Meaning | Source in the BOM view |
| --- | --- | --- |
| Measured | Counted or measured from the design | **Measured** |
| A number per something | That factor times the count. Change it in **Factor** | **Rule** |
| Factor you enter | The rule is set and the factor is blank, so the line starts as **! Needs factor** | **Rule** |
| You enter it | The line starts as **! Needs quantity** | **Manual** |

**When and how:**

| Wording | Meaning |
| --- | --- |
| — | Applies to every design, with a line whenever the layout has any to count |
| A design condition | The entry applies only then. Otherwise it is under **Not for this design** on the **Profile** card |
| Works | Installation or civil work rather than a supply item |
| Spare | The allowance follows **Spare for discrete consumables**, 5 % by default |
| Off by default | Listed under **Switched off** on the **Profile** card, with no line in the BOM |

Units are as the application prints them: Nos, set, m, t, m³, LS (lump sum) and MWp.
The abbreviations used are MMS (module mounting structure), SMB (string monitoring
box), ACCB (AC combiner box), ICR (inverter control room), IDT (inverter duty
transformer), MCR (main control room) and USS (unit substation).

## What feeds the lines

Most quantities come straight from the layout. These lines also read a design choice,
so they are the ones that move when you change it.

### Structure

The structure is bought as a package, not in parts.

- **MMS table (supply package)** has one line per table type, and its specification
  prints the table, module, tilt, clearance, wind and finish. For example: *"2P × 28
  portrait, full table (56 modules); module 2,380 × 1,130 mm, 580 Wp; tilt 8.4°; clearance
  0.5 m; wind …; Hot-dip galvanised"*. It includes the structure, fasteners and module
  mounting hardware, as per the supplier's design.
- **Tracker (supply package)** includes the structure, posts, drive, controller and
  module mounting hardware, as per the OEM. It is not split into interior and perimeter
  trackers. **Tracker control system** is one lump sum.
- **MMS pile** needs a pile pattern. See [Piles](/docs/editing/piles).

### DC protection

These lines read the Isc from the PAN file, and **Bifacial module** and **Max series
fuse** from the Array tab. The design Isc is the module's Isc, plus **Bifacial current
gain** when the module is bifacial.

| Item | Rule |
| --- | --- |
| Inline string fuse | **String fuse factor** × design Isc, then the next listed size |
| SMB input fuse | **String fuse factor** × strings per input × design Isc, then the next listed size |
| DC disconnector | **DC disconnector factor** × the most strings on an SMB × design Isc, then the next listed size |
| SMB inputs | The most strings on an SMB. With a Y that pairs, the most inputs any SMB uses |

The **Line** card prints the working, such as *"String fuse: 1.56 × 15.62 A = 24.3672 A
→ 25 A (Isc 14.2 A + 10 % bifacial)"*. Two warnings can appear, and neither changes the
status: *"The &lt;item&gt; needs &lt;n&gt; A, above the largest size in its list (&lt;largest&gt;
A)."* and *"The &lt;a&gt; A string fuse is above the module's &lt;b&gt; A maximum series
fuse."* The size lists are [BOM settings](/docs/bom/overview#bom-settings).

### DC harness and string fuses

**DC harness** and **String fuses** on the Electrical tab decide the connector lines.

| Harness | String fuses | Connector lines |
| --- | --- | --- |
| One string per input | Inline, or inline and inside the device | **DC connector, male** and **female**, plus **DC connector set with inline fuse** |
| One string per input | Inside the device, or none | **DC connector, male** and **female** |
| Y | Inline, or inline and inside the device | **Y connector set with fused arms**, one per pair |
| Y | Inside the device, or none | **Y connector set**, one per pair |

Under a Y, a string with a cable of its own keeps its own connectors. The DC solar cable
splits: each string's own cable before the Y is at **String
cable size**, and the shared cable after it at **Y pair cable size**.

### Cable laying

The laying choices on the [Cables card](/docs/inputs/cables) reach the BOM at the next
Generate.

| Laying | Lines it brings |
| --- | --- |
| DC string cable in conduit, buried or above ground | **HDPE DWC conduit · for DC cables**, along the route, and five manual conduit fittings |
| DC string cable, AC cable or DC trunk above ground | **Concrete block for above-ground laying**, the route divided by **Concrete block spacing**, rounded up |
| DC string cable above ground | **UPVC clamp · above-ground laying**, one per block |
| AC cable above ground | **UPVC clamp · above-ground laying of LV AC cable**, each cable divided by the spacing, rounded up |
| MV cable on tray | **Ladder cable tray · for MV cable**, along the MV route |

**Cable tie · DC cable along the tables and trackers** is counted with or without cables,
from **Cable tie spacing**.

### Communication and weather stations

| Choice | Lines |
| --- | --- |
| **Power-line, over the AC cable** | **SACU** and **PLC box**, one per ICR |
| **RS485, daisy-chained** | **RS485 cable**, and **Communication cable termination · RS485**, eight per cable end |
| A weather station | The station, 50 m of RS485 cable, 50 m of conduit and 16 terminations |
| Module sensors at every ICR | **Weather monitoring station · module temperature only**, one per ICR |

Each ICR with an MV run has **Optical fibre cable** as long as that run, so there is no
fibre without an MCR, USS or handover point. A chain longer than the limit in
[Advanced settings](/docs/workspace/advanced-settings) puts a remark on the RS485 line.

### MV network

The network is radial.

- **MV breaker panel (ICOG)**: one per ICR, with an incomer per IDT.
- **HT panel · at the MCR**: its incomers are the feeders and the USS links. **HT panel ·
  at a USS** follows the same idea. A handover point has no panel.
- **MV cable**: one row per cable schedule row, length × runs.
- **MV straight-through joint kit**: runs × one fewer than the number of drums a run
  takes, from **MV cable drum length**.
- **Inverter duty transformer**: split per rating and winding count, such as *"16,000
  kVA, 33 kV / 800 V, 5-winding, ONAN, Aluminium windings"*. See
  [ACCB and transformers](/docs/inputs/accb-and-transformers).

When a solar park provides the main control room, several of these go. See
[Grid connection by others](/docs/layout/grid-connection).

### Earthing

Earthing is measured from the project's earthing design, without opening its window:
pits by duty, strips by class, and two bolt sets per jumper or bridge. See
[Earthing design](/docs/simulation/earthing).

### Cleaning fleet and arresters

**Cleaning robot** and **Cleaning robot bridge** appear once a fleet is sized in
[Robotic module cleaning](/docs/simulation/robotic-cleaning), with one bridge line per
kind, standard or supported. **Lightning arrester, ESE** prints the protection level
and mast height in its specification, such as *"Level IV, 9 m mast"*. See
[Lightning arresters](/docs/layout/lightning-arresters).
