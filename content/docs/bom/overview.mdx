The bill of materials — the BOM — is a materials list computed from the layout
you have generated. It is a view of the plant: the **BOM** tab (**Ctrl+4**)
shows the list as a table in place of the plot, every cell in it is editable,
and the finished list prints as the **Bill of Materials** pages of the Detailed
Project Report.

It is not a separate document you keep by hand. The quantities are read out of
the plant, so a layout that changes and is generated again produces a
different list. What you add on top of that — extra line items, corrected
descriptions, remarks for a procurement team — is yours until the list is
rebuilt, and it is rebuilt both when you ask and after a Generate or a change
to the plant's grouping (see [What rebuilding does](#what-rebuilding-does)).

## The BOM view

Click the **BOM** tab, or press **Ctrl+4**. Generate a layout first: the list
is computed from a placed plant, and there is nothing to compute before one
exists.

The table takes the whole area under the view header. The left column hands
its inputs over to a green banner **● Bill of Materials** with an **Exit BOM**
button, and under it the **BOM TOOLS** panel; **Exit BOM** hands the column
back to the stage tabs. The status line reads *"BOM Mode ON — double-click any
cell to edit. It prints on its own page in the PDF."* The view tabs and the
tools beside them are described on [Views](/docs/workspace/views).

<Screenshot id="bom-view" />

The list is part of the session, so it is saved into the project file along
with the inputs, the layout and your sketch edits, and comes back when the
project is reopened. See [Projects](/docs/projects).

## The five columns

The table has a fixed set of columns, in this order.

| Column | What it holds |
| --- | --- |
| **S.No** | The line number, so a row can be referred to unambiguously in a purchase order or a query |
| **Material Description** | What the line item is |
| **Quantity** | How many, or how much |
| **Unit** | The unit the quantity is counted in |
| **Remark** | Free text — a specification, a make, a note to whoever prices the line |

**Quantity** and **Unit** are deliberately separate. A line counted in numbers
and a line counted in metres sit in the same table without ambiguity, which
matters as soon as cables and structures appear on the same list.

## BOM TOOLS

The panel in the left column holds everything that acts on the list.

<Screenshot id="bom-tools" maxWidth={360} />

| Control | What it does |
| --- | --- |
| **➕ Add Row** | Adds an empty row for you to fill in |
| **🗑 Delete Selected Row** | Removes the row you have selected |
| **⚙ Rebuild from Layout** | Discards the current list and computes a fresh one from the plant as it now stands |
| **BOM Template:** | A selector offering **Plant (auto-computed)** and the one built-in template that matches the current design |
| **📥 Load Template** | Opens the chosen template in a window of its own — see [Materials list templates](/docs/bom/templates) |
| **⬇ Export BOM to Excel** | Writes the list on screen as a spreadsheet |
| **⬇ Export BOM to PDF** | Writes the list on screen as a document of its own |
| **Hide Layout & Energy Summary** | Hides the row of plant chips under the view, so the table gets the full height of the window |

The hint under the buttons says what the panel is for: *"The main table is the
automated BOM. Load Template opens it in a separate window; edit it there,
then replace the plant BOM with it (used in the PDF)."*

Despite its label, **Hide Layout & Energy Summary** hides the chip row, not a
table. Untick it and the chips come back;
nothing is discarded.

### What rebuilding does

**⚙ Rebuild from Layout** is not a refresh that merges. It recomputes the
whole list from the current plant and puts that in place of what was there.

The list is also rebuilt **without a button and without asking**. After any of
these, the next time you open the BOM view the list is recomputed from the
layout:

- **Generate Layout**;
- a change on the **ACCB & Transformer** card (**Transformer** in a
  central-inverter design), which regroups the plant — see
  [ACCB and transformers](/docs/inputs/accb-and-transformers);
- loading an inverter file on a layout that already exists.

<Callout type="warn">
A rebuild discards your edits. Every row you added, every description you
corrected, every remark you typed, and a template you put in place of the
computed list, are replaced by the computed list. There is no merge and no
partial rebuild — the plant's own figures are the whole of what comes back.
Edit the list last, once the layout, the grouping and the inverter file are
settled.
</Callout>

That is the behaviour you want in one specific situation and not in any other:

- **Rebuild** after you have changed the plant without generating it again —
  added or deleted tables by hand, run the cleaning tool — and you want the
  quantities to match it. After drawing an obstruction or moving a control
  room, generate again instead: trench lengths are measured afresh only by a
  full cable run.
- **Do not rebuild** once you have started editing the list for real. Finish
  the layout first, rebuild once, then edit. The order costs nothing and saves
  the work.

If you need both — a fully edited list and a set of current quantities to
check it against — export the edited list to a spreadsheet before rebuilding,
then compare the two outside the application.

## Editing a cell

Double-click any cell and type. Every column is editable, including the
computed quantities — so a figure you overwrite is a figure you own from then
on, and it stands until the list is rebuilt.

Three edits are worth making even on a list you otherwise leave alone:

- **Descriptions.** The computed text is generic. Replacing it with the
  designation your organisation buys against turns the list into something a
  supplier can quote from.
- **Remarks.** Cable specifications, connector types, structure grades and
  finishes — the detail the layout has no way of knowing.
- **Missing line items.** Anything the plant's geometry cannot imply. Read the
  computed list against your own material take-off and add what is not in it.

For a starting point written for a reference plant of the same design, load
the built-in template rather than typing from scratch. See
[Materials list templates](/docs/bom/templates).

## Where the quantities come from

Two sources, and understanding the split tells you which figures move when you
change the design.

**The plant's own counts.** Everything the layout has placed and measured is
already known — the module count, the full and half tables or tracker units,
the inverter control rooms, the string inverters or string monitoring boxes,
the lightning arresters, the street lights, the piles, and the cable and trench
lengths. These are the same figures the Summary view reports, so the two never
disagree. See [Summary view](/docs/reference/summary-columns).

**The electrical grouping.** Some quantities are not placed on the ground and
are derived from rules instead: the AC combiner boxes (ACCBs), the inverter
duty transformers (IDTs) and the power transformer at the main control room.
The rules are yours, on the **ACCB & Transformer** card of the Electrical tab.
In each ICR block the inverters are shared onto ACCBs — at most 15 per box by
default — and the ACCBs onto transformers — at most 4 by default — and a block
whose load exceeds the transformer size limit is given more transformers. Each
transformer takes the smallest rating in your list at or above its load. The
power transformer is the whole plant's maximum AC output × the margin ÷ the
derating, rounded up to the next rating in its own list. The inverter file
supplies the loads and the low-voltage side, so without one the list carries
the counts but not the ratings.

The single-line diagram's automatic build, the Summary view and the cable
schedule read the **same grouping**, so the diagram and the materials list
agree on how many of each there are. The diagram never reads this list:
editing it, or loading a template, does not change the diagram. See
[Building a diagram from the plant](/docs/sld/auto-build).

### What the list contains

The rows come out in a fixed order. A row whose quantity would be zero is
**left out altogether**, so a short list is not a fault — it means the plant
has none of that item.

| # | Description | Unit | Quantity and remark |
| --- | --- | --- | --- |
| 1 | Plant AC Capacity | MW | Two decimals, or `—` until an inverter file is loaded. Remark *"PmaxOut × no. of inverters (from OND)"*, or after a Simulation with AC capacity *"AC capacity requested in the AC-capacity simulation"* |
| 2 | Plant DC Capacity | MWp | Three decimals |
| 3 | PV Module | Nos | The wattage of each |
| 4 | String Inverter, **or** SMB (String Monitoring Box) | Nos | The capacity of each inverter in kWp; or the SMBs per central inverter |
| 4b | Central Inverter | Nos | Central inverter only |
| 5 | MMS Table (Module Mounting Structure) — Full, **or** Tracker (Full) | Nos | — |
| 6 | Half MMS Table (Module Mounting Structure), **or** Half Tracker | Nos | *"half length; carries half the strings"* — only when the plant has any |
| 7 | DC String Cable | m | *"incl. +ve / −ve conductors"* |
| 8 | DC String Trench — **DC String Trench (est.)** on a very large plot | m | Where the trench runs — *"MMS/Tracker → String Inverter"*, or *→ SMB* — and, when estimated, *"; drawn for a sample of clusters, scaled to all tables"* |
| 9 | DC Cable (SMB → Central Inverter) | m | Central inverter only. A design-warning remark, if any |
| 10 | AC Cable (Inverter → ICR) | m | String inverter only. A design-warning remark, if any |
| 11 | AC Trench (Inverter → ICR), **or** DC Trench (SMB → Central Inverter) | m | A design-warning remark, if any |
| 12 | ACCB (AC Combiner Box) | Nos | String inverter only. *"≤ 15 inverters each"*, following the card's **Inverters per ACCB, max** |
| 13 | Inverter Duty Transformer (IDT) | Nos | The voltages, the ratings and the most feeders on one transformer, such as *"33 kV / 800 V; 4 × 16,000 kVA; ≤ 4 ACCB/Tx, one LV winding each"* (*C.Inv/Tx* in a central-inverter design). Without an inverter file: *"33 kV / LV from the OND; 4 · rating needs OND; ≤ 4 ACCB/Tx, one LV winding each"* |
| 14 | ICR (Inverter Control Room) | Nos | A design-warning remark, if any |
| 15 | MV Panel (Switchgear) | Lot | *"Inside MCR"* — only once a main control room is placed |
| 16 | MV Cable (ICR → MCR) | m | Main control room only |
| 17 | MV Trench (ICR → MCR) | m | Main control room only |
| 18 | Power Transformer | MVA | Main control room only. The rating, such as *63* or *2 × 80*, with its basis as the remark, such as *"Σ PMaxOut 58.1 MVA × margin 1 ÷ derating 1 = 58.1 MVA → next listed rating"*. Without an inverter file the quantity is `—` and the remark *"needs the inverter file (OND)"* |
| 19 | MCR (Main Control Room) | Nos | Main control room only |
| 20 | Lightning Arrester | Nos | — |
| 21 | Street Light (perimeter) | Nos | Pole height and spacing |
| 22 | Robotic Module Cleaning Equipment | Nos | The row count, and any robots added for broken lines or battery range |
| 23 | Cleaning Robot Bridge (table-to-table) | Nos | *"Gaps ≤ … m"* |
| 24 | Cleaning Robot Bridge (supported span) | Nos | *"Over arresters / buildings / obstructions"* |
| 25 | Design warning | — | Only for a design warning whose own row is absent: a *"Check: …"* remark, with no quantity or unit |

In the IDT remark the MV figure is the card's **MV voltage** and the LV figure
the inverter file's output voltage.

### Design-warning remarks

When the layout breaks a design rule, the row the warning concerns carries a
remark starting **Check:** and is tinted in the warning colour, with the remark
as its tooltip. Control-room warnings go on **ICR (Inverter Control Room)**;
feeder and voltage-drop warnings on **AC Cable (Inverter → ICR)** or **DC Cable
(SMB → Central Inverter)**; trench warnings on the AC or DC trench row. Several
on one row are joined with a semicolon. A warning whose row is not on the list
gets a row of its own, **Design warning**. The remarks travel into the Excel and
PDF exports and the report. See
[Design warnings](/docs/reference/design-warnings).

Four things change which rows appear:

- **A tracker plant** carries **Tracker (Full)** and **Half Tracker** in place
  of the two table rows.
- **A central-inverter plant** carries **SMB (String Monitoring Box)** and
  **Central Inverter** in place of **String Inverter**, adds **DC Cable (SMB →
  Central Inverter)**, and its second trench row is the DC trunk trench —
  there is no AC leg. See [Choosing a design mode](/docs/design-modes).
- **Running without cable calculation** leaves the string, AC and DC-trunk
  cable and trench rows at zero, so they drop out.
- **Not placing a main control room** drops rows 15 to 19, from the switchgear
  panel down to the room itself.

### The cleaning robot fleet

Rows 22 to 24 appear only after you have run the cleaning tool. Run
**🤖 Robotic Module Cleaning** on the Tools tab, decide which wide gaps you
will bridge, and click its **Add n robots + m bridges to BOM** button. The
fleet then feeds both the Summary view's **Cleaning robots** row and this list.
Until you do, there is no fleet on the list at all.

That is deliberate. A cleaning fleet is a purchase decision with a bridge count
attached to it, not something a layout implies, so the list never carries a
fleet you did not ask for. See
[Robotic module cleaning](/docs/simulation/robotic-cleaning).

### What the list does not carry

**Earthing materials are not in the bill of materials.** Earth pits, GI strip,
earthing cable and the fittings that go with them come only from the
**Earthing Design** study, whose bill of quantities exports on its own. See
[Earthing design](/docs/simulation/earthing).

## Exporting the list

Two exports on the tools panel, both of the list on screen rather than the
computed one — whatever you have edited is what is written.

| Button | What you get |
| --- | --- |
| **⬇ Export BOM to Excel** | The five columns as a spreadsheet, for pricing, sorting and merging into a wider procurement sheet |
| **⬇ Export BOM to PDF** | The list as a document of its own, for circulation and sign-off |

<Screenshot id="bom-page" />

These are separate from the report. **Export ▾ ▸ Export Detailed Project
Report**, in the view header, writes a Word document that already carries the
materials list as its **Bill of Materials** annexure, paginated across as many
pages as the list needs, alongside the drawing, the summary and the diagram —
and **Export PDF (with Piles)** carries the same pages while the pile overlay
is on. Use the standalone buttons when you want the list on its own; a
purchasing department rarely wants the engineering drawing attached to it.
See [The Detailed Project Report](/docs/exports/project-report).

## What the list is, and is not

State this to whoever receives it, because it sets what they can do with it.

- **It is a materials list, not a priced bill of quantities.** There is no
  rate column, no amount column and no total. Pricing happens after the
  export, in the spreadsheet.
- **The descriptions are generic.** They describe the item, not a supplier's
  catalogue part. Nothing here is tied to a make, a model or a stock code
  until you type one in.
- **It follows from a layout, so it inherits the layout's assumptions.** Cable
  quantities exist only if cable calculation was on for the run; a fleet
  exists only if you sized one; arresters exist only if you asked for them. A
  missing row on this list is usually a setting rather than an absence.
- **Nothing is checked against a standard.** Quantities are counts and
  lengths, not a verified schedule of material.

## A working order

The list is cheapest to produce if the plant is finished before you start
editing it.

<Steps>
<Step>
### Finish the layout

Generate, place the main control room, draw any obstructions, and make your
hand edits in Sketch Mode. See [Sketch Mode](/docs/editing/sketch-mode).
</Step>

<Step>
### Turn cable calculation on and generate again

Cable and trench lengths are only computed when you ask for them, and they
are usually the largest quantities on the list. See
[Cable routing](/docs/layout/cables).
</Step>

<Step>
### Size the cleaning fleet, if you want one

Run **🤖 Robotic Module Cleaning**, settle the bridge decisions, and add the
result to the BOM, so the fleet count is on the list before you rebuild.
</Step>

<Step>
### Settle the grouping

Load the inverter file and set the **ACCB & Transformer** card before you edit
the list: a change to either rebuilds the list on your next visit to the BOM
view, and your edits go with it.
</Step>

<Step>
### Open the BOM view and rebuild once

Click the **BOM** tab, then **⚙ Rebuild from Layout** for a list that matches
the finished plant.
</Step>

<Step>
### Edit, then export

Correct the descriptions, add the line items the layout cannot know about,
and export to a spreadsheet, a PDF, or the report. From here on, avoid
rebuilding.
</Step>
</Steps>
