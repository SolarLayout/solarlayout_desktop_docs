---
title: Licence problems
description: Every access state the License / Subscription window shows, what each one means, and the fix — plus the 3-day offline grace.
---

The access-status chip in the top toolbar always shows this device's status at
a glance (with a **Get Free Access** or **Contact Us** button beside it when
action is needed) — or open **Help ▸ License / Subscription…** for the same
detail plus the Device ID. The License / Subscription window's headline is
always one of three: **✓  Active**, **✗  No access**, or **⏳  Waiting for
activation** — the text beneath it says which state applies and why.

There is no licence file to find, copy or keep safe. Access is tied to this
computer through its **Device ID** — the Windows registry value also shown
under Settings ▸ System ▸ About ▸ Device ID — and checked online with the
server.

## The states

<Accordions>

<Accordion title="Access active">

**What it means.** This device has active access. The headline reads
**✓  Active**, with the sub-text "You have access until &lt;date&gt;."
underneath. The buttons beneath it are **Access Details**, **Refresh** and
**Close**.

<Screenshot id="licence-valid" />

**Nothing to fix.** **Generate Layout**, every export, and the SLD and BOM
tools all work.

</Accordion>

<Accordion title="Your access has ended. Contact SolarLayout to purchase a licence.">

**What it means.** This device's access has expired. The headline reads
**✗  No access**, and **Layout generation is disabled until your access is
active.**

**Fix.** Contact SolarLayout at
[sales@solarlayout.app](mailto:sales@solarlayout.app) to arrange paid access
for this device, then click **Refresh** once it is issued.

</Accordion>

<Accordion title="Access has been revoked. Contact SolarLayout.">

**What it means.** Access for this device has been withdrawn. The headline
reads **✗  No access**.

**Fix.** Contact SolarLayout to resolve it, then click **Refresh**.

</Accordion>

<Accordion title="No active access for this device. Click 'Get Free Access' to get started.">

**What it means.** This device has never had access requested for it, or a
previous request was never completed. The headline reads **✗  No access**.

<Screenshot id="licence-no-licence" />

**Fix.** Click **Get Free Access**. The application opens your browser at the
activation page for this device
(`https://solarlayout.app/desktop/solarlayout?device=<DeviceID>`). Complete
activation there, then switch back to the window — it re-checks automatically
and flips to **✓  Active** without needing a manual **Refresh**. See
[Activate your licence](/docs/licence/activate).

</Accordion>

<Accordion title="Waiting for activation">

**What it means.** This is shown right after clicking **Get Free Access**,
while activation is being completed in the browser.

**Fix.** Finish activating on the page that opened, then switch back to the
License / Subscription window. It checks again on its own; **Refresh** does
the same thing if you want to trigger it directly.

</Accordion>

<Accordion title="Could not verify access — connect to the internet and try again.">

**What it means.** The application could not reach the server and has no
usable cached result to fall back on.

A good check is cached, so a brief outage does not stop work: the application
keeps working under its last known status for up to **3 days** without a
connection. This message only appears once that offline grace has run out, or
on a machine that has never checked in successfully.

**Fix.** Reconnect to the internet and click **Refresh**. If the message
persists on a machine that is definitely online, contact SolarLayout — see
[Getting help](/docs/support).

</Accordion>

</Accordions>

## Other situations

<Accordions>

<Accordion title="Generate Layout is blocked">

Clicking **Generate Layout** — or an export, or the SLD or BOM tools — without
active access shows a **Subscription Required** dialog: *"Layout generation is
locked."*, then the reason for the current state, then *"Open Help ▸ License /
Subscription… to view your Device ID and start your free trial."* The License
/ Subscription window then opens itself so you can act on it immediately.

<Screenshot id="licence-blocked-generate" />

Read the headline in the window it opens and find that state above.

</Accordion>

<Accordion title="I updated or reinstalled the application and access is gone">

It should not be. Access is server-side and tied to the Device ID, not to any
file on disk, so it survives updates and reinstalls automatically — there is
nothing to re-load.

If the window still reports **✗  No access** after an update or reinstall:

1. **Click Refresh** in the License / Subscription window — the app may simply
   not have checked in yet since the update.
2. **Check the machine's internet connection.** The check needs to reach the
   server at least once after install.
3. **Compare the Device ID** shown now against what you activated with. It
   should be unchanged after an update; a full reinstall of Windows, or a move
   to a different computer, is what changes it — not an application update.

</Accordion>

<Accordion title="A second Windows user account shows no access">

It should not. The Device ID comes from the machine, not the Windows user
account, so a second account on the same PC reports the same Device ID and the
same access — unlike an older per-user file would have. If the second account
shows **✗  No access**, click **Refresh**; if that does not resolve it, follow
[What to send when you ask for help](#what-to-send-when-you-ask-for-help)
below.

</Accordion>

<Accordion title="What to send when you ask for help">

Send all of this in one message, so access can be checked without a round
trip:

- **The Device ID**, copied with the **Copy** button in the License /
  Subscription window — not retyped.
- **The exact headline and message text** the window shows, including any
  date it names.
- **The email address used when you got access**, if any.
- **The app version**, shown in the bottom status bar.

Send it to SolarLayout at
[sales@solarlayout.app](mailto:sales@solarlayout.app), or use **Contact Us**
in the License / Subscription window to open the same route.

</Accordion>

</Accordions>
