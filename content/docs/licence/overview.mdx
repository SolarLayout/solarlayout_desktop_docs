title: How licensing works
description: The application is licensed per machine for a subscription period. What a licence unlocks, why it cannot be edited, and the checks it must pass.
---

SolarLayout Desktop is licensed **per machine for a subscription period**. One
licence covers one computer, and it carries a start date and an expiry date.

The licence controls one thing: whether a layout can be generated. It does not
decide which features you have — every button, every input group and every
export exists in the application whether or not a licence is present.

## What works without a licence

The application opens, and the interface is complete. You can:

- read and change every input in the panel, and see every default;
- load a boundary file and have it read;
- open every menu, the in-app guide, and the licence window itself.

What you cannot do is **Generate Layout**. Clicking it without a valid, in-date
licence for this machine produces a message instead of a layout.

<Screenshot id="licence-blocked-generate" />

Because almost everything downstream is computed *from* a generated layout —
energy yield, the bill of materials, the diagram, every export, the satellite
and pile views — a machine without a licence is in practice limited to
exploring the inputs. That is deliberate: you can install the application,
walk through the settings and see what the design will ask of you before a
licence exists.

## One licence, one machine

The licence window shows a **Device ID** — a value that identifies the computer
you are sitting at. A licence is issued against that Device ID, and the
application checks the two match on every start.

The practical consequences:

- A licence file that works on one computer will **not** work on another. It
  fails with *"License is issued for a different computer"*.
- Copying `license.lic` to a colleague's PC achieves nothing.
- A new or rebuilt machine needs its own licence, issued against its own
  Device ID.

[Activate your licence](/docs/licence/activate) covers the four steps.

## Why editing the licence file cannot work

A licence is a small file carrying two things: the details of the licence — the
machine it is for, when it starts, when it ends — and a **signature** over those
details.

Signatures here work on a key pair: two matching halves, one that can create a
signature and one that can only check it. **Your copy of the application carries
only the checking half.** It can confirm that a signature belongs to the details
beside it. It cannot produce a signature, and it cannot alter one.

So changing a single character of the file — a later expiry date, a different
Device ID, even a stray space added by a text editor — leaves a signature that
no longer matches the details. The application does not silently repair it or
ignore it. It refuses the file with *"License signature invalid (tampered or
wrong key)"*.

This is in your interest as much as the vendor's:

- **Nobody can forge a licence for your machine either.** The half of the key
  pair that creates signatures is not on any customer's PC, so a licence
  cannot be manufactured on one.
- **The check is local.** It runs on your own machine and needs no internet
  connection, so a plant design is never blocked by a licence server being
  unreachable or by a site with no connectivity.
- **A silent failure is impossible.** Either the file verifies and works, or you
  get a named message telling you which check stopped it.

<Callout type="warn">
Never open `license.lic` in a text editor and save it. Some editors add a
line ending or change the character encoding on save, and that alone is enough
to invalidate the signature. Keep the file exactly as you received it.
</Callout>

## The eight checks

Every start applies the same checks, in this order. All eight must pass. They
run in sequence, so if more than one thing is wrong, the message you see names
whichever comes first in the list.

1. **A licence file is present and readable.** Otherwise: *"No license found"*.
2. **The file is a complete licence.** It must carry both the licence details
   and the signature over them, intact.
3. **The signature matches the details.** This is the check that fails when a
   file has been edited or damaged in transit.
4. **The machine matches.** The Device ID in the licence must be this
   computer's.
5. **The system clock has not been set backwards.** The application records the
   latest date it has seen and compares the current clock against it.
6. **A usable expiry date exists.** A licence with no readable end date is
   refused rather than treated as unlimited.
7. **Today is not before the start date.** A licence issued ahead of its
   subscription period does not work early.
8. **Today is not after the expiry date.**

Each failure has its own message. [Licence problems](/docs/licence/troubleshooting)
lists all seven of them, with the likely causes and what to do about each.

## Where the licence is stored

| Path | What it holds |
| --- | --- |
| `%APPDATA%\SolarLayout.Desktop\license.lic` | The licence itself — the location the application reads on every start. |
| `%APPDATA%\SolarLayout.Desktop\.lastseen` | The clock record — the latest date the application has seen — used by check 5. |

`%APPDATA%` is **per Windows user account**. A second user account on the same
PC has its own folder and does not see the first account's licence, even though
the machine's Device ID is the same.

A licence file placed beside the application itself is also read, as a
read-only fallback. Loading the file through the licence window is the
supported route and the one to use.

Because the licence sits outside the application, replacing the application
leaves it in place — and on first run the application adopts a licence left by
a previous installation. Updating does not cost you an activation. See
[Updates and reinstalling](/docs/install/updates).

## What a licence is not

- It is **not** tied to a person or an email address. The email is how the
  vendor knows who to issue to and where to send the file; the machine is what
  the licence is checked against.
- It is **not** a feature switch. There is no part of the interface that appears
  or disappears with a licence.
- It does **not** need to be renewed inside the application. A renewal is a new
  file, loaded exactly the way the first one was.
