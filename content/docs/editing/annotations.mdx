A layout is a set of positions. A drawing is a layout somebody can build from:
it carries the dimensions that matter, the labels that name things, a north
arrow, a scale, and the notes that explain the parts a plan view cannot show.
The annotation tools in Sketch Mode are how you turn the first into the second
without leaving the application.

Annotations are drawing content. They do not clear ground, they are not
counted in the plant totals, and they never change the capacity — that is the
difference between them and the plant objects on
[Sketch Mode](/docs/editing/sketch-mode). They stay with the project, on screen
and in **Export ▾ Export Image (PNG)**. The one exception is a line drawn with a
width, below, which does clear ground.

## Getting to the tools

Click **Sketch** in the Layout view's tools. Every tool on this page is in the
same palette as the editing tools — the **DRAW**, **ANNOTATE**, **MODIFY
SELECTION**, **IMPORT & CLEAR** and **COMMAND** groups — and one tool is active
at a time.

Each element you draw is created on the **active layer**, in the current stroke
colour, and can be put into a group. The default stroke is an orange-red,
1.5 pt wide; **🎨 Colour** on the contextual bar above the plot changes it for
what you draw next.

## Drawing shapes

The **DRAW** group shows four tools, with four more behind the **More shapes**
expander. The multi-point tools end with a right-click; **∿ Spline** and
**▨ Fill/Zone** also take a double-click.

<Screenshot id="sketch-palette-more-shapes" />

| Tool | What you do |
| --- | --- |
| **╱ Line** | Click and drag a straight line, then answer the **Line width** prompt |
| **⌒ Polyline** | Click each vertex; right-click to finish; then answer the **Line width** prompt |
| **□ Rect** | Click and drag a rectangle |
| **○ Circle** | Click the centre, then drag the radius |
| **◜ Arc** *(More shapes)* | Click the start, then the end, then a point on the arc |
| **⬭ Ellipse** *(More shapes)* | Click and drag a bounding box |
| **∿ Spline** *(More shapes)* | Click the fit points; right-click or double-click to finish |
| **▨ Fill/Zone** *(More shapes)* | Click the points of the zone; right-click or double-click to finish |

Three of those deserve a note.

**╱ Line and ⌒ Polyline ask for a width.** Enter **0** and you get a line only —
an annotation like any other. Enter more than 0 and the line becomes a
**corridor** of that width that removes the tables under it, as the **⚡ T-Line**
tool does. It is the way to clear an irregular strip — a drain, a track that bends
— that a straight centre-line cannot describe.

**◜ Arc takes three clicks in a specific order** — start, end, then a point the
arc must pass through.

**▨ Fill/Zone is a filled polygon of its own.** Click its corners and finish
with a right-click. It is the tool for marking out a phase, a contractor's work
area, or a land parcel that is not an exclusion.

Switch **⊾ Ortho** on before drawing anything that has to run square, and leave
**🧲 Snap** on — it is on by default — for anything that has to meet existing
geometry exactly.

### Typing a point instead of clicking it

The numeric entry on the contextual bar replaces the second click of any tool.
Click a start point, then type into the bar and press Enter:

| You type | You get |
| --- | --- |
| `25.4<30` | 25.4 m at a bearing of 30° |
| `10,5` | 10 m east and 5 m north of the start point |
| `25.4` | 25.4 m along the cursor direction — or a radius, for a circle |

That is how a boundary offset, a fence setback or a trench of a known length
goes onto the drawing at its real dimension rather than at a guess.

## Text labels

**🅣 Text** places a label. Click where the label goes and an **Add text**
prompt takes the text — it accepts more than one line, so a note does not have
to be a single long string — and the label sits at that position on the plot.

To reposition a label, switch to **↖ Move** and drag it. Labels select, move
and delete like any other element.

Text is the tool that carries the things the geometry cannot say: a plot name,
a phase number, an access route, a caveat about a survey.

## Measuring

**📏 Measure** answers a question; it does not add anything to the drawing and
nothing it shows is saved.

| Points you click | What you get |
| --- | --- |
| Two | The distance between them and the bearing from the first to the second |
| Three or more, then double-click or right-click | The area and perimeter of the shape, with the angle at each vertex |

Each click snaps to corners, edge midpoints and centres of what is already on
the plot, so a measurement between two tables is between the tables, not
between two points near them. **Esc** clears the measurement.

The bearing on a two-point measurement is what makes this useful for setting
out — it is the number you hand to a surveyor along with the distance. The area
is for the questions a plan view raises: how much ground a phase covers, or the
size of the parcel a fence encloses.

All geometry is held in metres on the ground, so a measurement is a ground
distance, not a screen distance. Zooming does not change it.

## Dimensions

**📐 Dimension** places a dimension that stays on the drawing: click and drag
between the two points, or click a start point and then type a length into the
numeric entry. It is saved with the project and redrawn with the plot.

The distinction between the two tools is worth being deliberate about:

| Aspect | **📏 Measure** | **📐 Dimension** |
| --- | --- | --- |
| Purpose | Check a distance now | Record a distance for someone else |
| Stays on the drawing | No | Yes |
| Saved with the project | No | Yes |

Dimension the things a construction team would otherwise have to derive: row
pitch, the gap between table runs, the setback from the fence to the first row,
the clearance around a control room. Those are the numbers that get queried on
site. To send them out, export the view as an image, as described under
[What reaches an export](#what-reaches-an-export).

## Modifying a selection

The **MODIFY SELECTION** group acts on whatever is currently selected with
**↖ Move**, and stays greyed out until a selection exists that it can act on.

<Screenshot id="sketch-palette-selection" />

| Tool | What it asks | What it does |
| --- | --- | --- |
| **⟳ Rotate** | An angle, in degrees clockwise | Turns the selection |
| **⤢ Scale** | A factor | Enlarges or shrinks the selection |
| **⇋ Mirror** | Left↔right or top↔bottom | Flips the selection |
| **⇥ Offset** | A perpendicular distance | Places a parallel copy of a line or shape at that distance |
| **▤ Array** | A rectangular or polar pattern | Repeats the selection in a grid or around a centre |
| **⧉ Group** | — | Groups the selected annotations so they select and move together; needs two or more annotations selected |
| **⿲ Ungroup** | — | Breaks the group apart again |

A group moves as one. Select the elements that belong together — a dimension
and the label that explains it, an outline and its fill — group them, and from
then on **↖ Move** picks up the whole thing. Ungroup when you need to change
one part. Groups are independent of layers: an element carries a layer and,
optionally, a group, and grouping elements does not move them onto a layer of
their own.

## Layers

Layers control what is visible on screen. The three layer controls sit on the
contextual bar above the plot, not in the palette:

| Control | What it does |
| --- | --- |
| **Layer** | The active layer — everything you draw goes onto it. Starts at *0* |
| **＋** | Creates a new layer and makes it active |
| **👁** | Shows or hides the active layer |

Create the layer first and then draw. The habit that pays off is one layer per
audience — dimensions on one, civil notes on another, a client's mark-ups on a
third — because then you can show one and hide the rest instead of deleting
anything.

## What reaches an export

Annotations belong to the project and to the screen.

| Output | What it carries |
| --- | --- |
| **Save project** | Every annotation, dimension and layer |
| **Export ▾ Export Image (PNG)** | The plot as it is on screen, so whatever annotations and layers are showing |
| The [deliverables package](/docs/exports/deliverables) | The design, drawn on its own standard layers. Annotations, dimensions and your layers are not in its drawings or its CAD twin |

Hand-drawn cable trenches are plant rather than annotation, so they do reach the
package.

## Bringing an existing drawing in

**📂 Import DXF** brings a CAD drawing onto the canvas so you can draw against
it — an existing site plan, a survey, a road alignment, a neighbouring
developer's drawing. It is a reference to work over, not an input to the layout:
importing a drawing does not create obstructions and does not move any tables.

The drawing's coordinates are read **in the boundary drawing's own frame**. Nothing
is scaled, re-centred or fitted to the plant. A site read from a Google Earth file
sits in its UTM zone, so the reference must be in that zone too. A CAD boundary you
placed by hand, or one laid out without a location, moves by one offset with its
plant, so a reference in the boundary drawing's coordinates overlays it.

<Callout type="warn">
Import a drawing that is not in those coordinates — one drawn around a local origin,
say — and it will not appear over the plant. It lands wherever its own coordinates put
it, usually far enough away to be off the visible canvas altogether. Click **Home** in
the Layout tools to fit the view and you will see how far out it went.
</Callout>

Seven entity types come across: lines, polylines, circles, arcs, ellipses,
splines and text. Anything else in the file is skipped. The elements land on the
**active layer** and are editable like anything you drew, and the status line
reports how many came in and onto which layer — so pick or create that layer
before importing.

To turn something in an imported drawing into ground the layout must avoid,
draw it as a road, a corridor or an obstruction. See
[Obstructions](/docs/layout/obstructions).

## The scale bar and north arrow

**🧭 Scale bar + N** switches a metric scale bar and a north arrow on and off
together. They belong on anything that leaves the application as a picture, such
as **Export ▾ Export Image (PNG)**.

<Screenshot id="scale-bar-north" />

The sheets of the [drawing set](/docs/exports/drawing-set) draw their own grid north,
scale bar and title block, so you do not need this for the package.

## Clearing annotations

**🗑 Clear Annotations** removes the annotation elements in one action.

<Callout type="warn">
**🗑 Clear Annotations** clears the drawing content wholesale, not only the
selection. If the aim is only to get annotations out of the way — to read the
layout underneath, or to take a clean capture — hide the layer with **👁**
instead, and everything is still there when you show it again.
</Callout>

Plant objects are not annotations, so clearing annotations does not remove
tables, arresters, roads or trenches. Those are deleted with **🗑 Delete** and
**✂ Del Trench**.

## Working from the keyboard

The **COMMAND** line at the foot of the palette takes typed aliases. If you
draft in CAD every day, it is faster than finding a button: type the alias,
press Enter, and the tool is armed. Its placeholder lists them: *"cmd: L PL REC
C ARC EL SPL H DIM RO SC MI O AR ↵"*.

| Type | Tool |
| --- | --- |
| `L` | **╱ Line** |
| `PL` | **⌒ Polyline** |
| `REC` | **□ Rect** |
| `C` | **○ Circle** |
| `ARC` | **◜ Arc** |
| `EL` | **⬭ Ellipse** |
| `SPL` | **∿ Spline** |
| `H` | **▨ Fill/Zone** |
| `DIM` | **📐 Dimension** |
| `T` | **🅣 Text** |
| `RO` | **⟳ Rotate** |
| `SC` | **⤢ Scale** |
| `MI` | **⇋ Mirror** |
| `O` | **⇥ Offset** |
| `AR` | **▤ Array** |
| `U` | **↶ Undo** |
| `RE` | **↷ Redo** |
| `M` | **📏 Measure** |
| `S` | **↖ Move**, for selecting |

The aliases are the ones a CAD user already has in their fingers, so a drafting
session runs at keyboard speed: `PL`, click the vertices, right-click, `DIM`,
drag, `T`, type the note. The full keyboard reference is in
[Keyboard and commands](/docs/reference/keyboard-and-commands).

## What to put on a picture you hand over

The tools are general, so the useful question is which of them a recipient actually
needs. This is the set that answers the questions a design picture gets asked on site.

| Add | With | So that |
| --- | --- | --- |
| Row pitch, and the gap between table runs | **📐 Dimension** | Nobody sets out spacing from a scaled print |
| The setback from the fence to the first row | **📐 Dimension** | The perimeter road width is visible as a built dimension, not an assumption |
| Clearance around each control room | **📐 Dimension** | The access the equipment needs is on the picture |
| Plot and phase names | **🅣 Text** | A multi-plot site can be discussed plot by plot |
| Access routes and gates | **⌒ Polyline** at width 0, plus **🅣 Text** | The route to each part of the plant is agreed before mobilisation |
| Contractor or phase work areas | **▨ Fill/Zone** | Two teams on site know where their boundary is |
| Scale and orientation | **🧭 Scale bar + N** | The picture survives being printed, cropped or pasted |

Keep each of those on a layer that says who it is for, and show only that layer when
you export the image, so one project serves the client, the civil contractor and the
electrical contractor without being redrawn three times.
